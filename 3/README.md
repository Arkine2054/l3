# CommentTree

**Древовидные комментарии с навигацией, поиском и быстрым просмотром веток**

Cистема комментариев с поддержкой древовидной структуры,
быстрым переходом по узлам, полнотекстовым поиском и удобным интерфейсом для чтения больших веток обсуждений.

---

## Возможности

*   **Древовидная структура комментариев (N уровней глубины)**
*  **Поиск по тексту комментариев**
*  **Навигация по веткам**:

    * развернуть/свернуть ветви
    * переход к родителю
    * переход к корневому комментарию

---

## Архитектура проекта

```
/cmd
  /api            — HTTP API сервера
/internal
  /models         — структуры данных
  /repository     — логика работы с БД
  /service        — бизнес-логика дерева
/web              — фронтенд (HTML/JS/CSS)
/db/migrations    — SQL миграции
```
## API

### Получить список комментариев (дерево)

```
GET /comments
```

### Получить ветку по корневому ID

```
GET /comments/{id}/tree
```

### Добавить комментарий

```
POST /comments
{
  "parent_id": 1,
  "author": "Alex",
  "content": "Hello world!"
}
```

### Поиск

```
GET /search?q=keyword
```

### Удаление

```
DELETE /comments/{id}
```
